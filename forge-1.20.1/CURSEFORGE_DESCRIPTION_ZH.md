# Find Me

**把坐骑、伙伴和载具真正带在身边。**

Find Me 是一个面向 Minecraft 1.20.1 Forge 的生物管理模组。它可以绑定来自原版或其他模组的生物，将它们整理到轮盘、队伍、仓库和小窝中，并在需要时完成召唤、切换、跟随、战斗指挥与高空救援。

它不只是一个“传送宠物”的按键。不同移动类型的生物会以适合陆地、天空或水域的方式赶来；旧坐骑会离场，新坐骑会接近玩家；当玩家从高处坠落时，合适的坐骑还可以执行救援。

## 主要特性

### 坐骑与伙伴轮盘

- 将已驯服或符合所有权要求的生物绑定到 Find Me。
- 坐骑与伙伴使用独立轮盘，支持多页和快捷切换。
- 短按快速召唤当前选择，长按打开轮盘，松开确认槽位。
- 再次打开轮盘时会优先回到当前召唤生物所在的页面。
- 支持召回、仓库存放以及召唤数量限制。

### 动态召唤、切换与救援

- 根据生物能力区分陆地、飞行和水生移动。
- 生物会从安全位置出现并向玩家靠近，而不是简单砸在玩家身上。
- 玩家移动或奔跑时，召唤与切换过程会相应调整追赶速度。
- 坐骑切换包含旧坐骑离场和新坐骑接近过程。
- 高处坠落时可触发坐骑救援；低高度仍会救援，但会跳过不必要的等待动画。
- 提供粒子、音效、字幕对话和召唤动画设置。

### 生物指令轮盘

对当前生物或整个编队下达命令：

- 跟随我、原地待命、向前移动
- 移动到准星位置、在此守卫、保护我
- 攻击准星目标、停止当前指令
- 飞行生物降落
- 回家、骑乘回家、召回全队
- 在生物和适配内容支持时使用治疗、魔法攻击、魔法保护和魔法支援

已绑定的 Find Me 生物不会被自动协防或攻击指令误判为敌人；友伤保护开启时，玩家与自己的伙伴也不会互相造成伤害。

### 管理器、队伍与仓库

管理器提供完整的可视化界面：

- 创建、删除和整理伙伴队伍
- 自动加入队伍、自动创建队伍和自动补位
- 在队伍与仓库之间移动成员
- 查看生物模型、生命值、状态、位置和详细资料
- 调整轮盘槽位、召唤状态和伙伴部署数量
- 搜索大量已绑定生物
- 管理死亡、濒死、恢复记录与安全备份

### 小窝

放置“小窝”后，可以把伙伴安排到世界中的固定居所：

- 每个小窝独立设置容量、游荡范围和最大活动边界
- 一键切换休息、游荡或守卫模式
- 小窝居民会在附近活动，并在守卫模式下共同处理真正的敌对目标
- 生物进入濒死状态后会在小窝中休养，缓慢恢复生命，满血后自动重新出现
- 小窝设置只属于当前方块；拆除后重新放置会生成新的独立设置

### 生存与数据安全

- 生物濒死保护与恢复流程
- 定时安全备份及手动恢复点
- 睡眠恢复选项
- 防止绑定生物死亡时重复掉落物品
- 伙伴方块保护可阻止绑定生物的爆炸、踩踏和直接方块破坏，同时保留对实体的正常战斗效果
- 数据检查与恢复工具可用于排查损坏的队伍、仓库、小窝或实体快照

### 载具支持

除了生物，Find Me 还提供载具绑定器：

- 使用“载具绑定器”绑定支持的载具
- 从载具轮盘中召唤和收回载具
- 使用“定位坐垫”设置载具座位
- 普通右键仍优先保留生物或载具原本的交互；只有召唤、切换等必要阶段会临时接管骑乘

## 基本操作

| 默认按键 | 功能 |
| --- | --- |
| `R` | 坐骑召唤 / 救援；长按打开坐骑轮盘 |
| `V` | 伙伴召唤；长按打开伙伴轮盘 |
| `G` | 打开 Find Me 管理器 |
| `C` | 打开当前生物能力轮盘（存在可用能力时） |
| 未绑定 | 打开当前生物指令轮盘，请在“控制”中自行设置 |

轮盘操作采用“按住打开、移动选择、松开确认”。所有按键都可以在 Minecraft 的控制设置中重新绑定。

## 如何开始

1. 制作“名纸”。
2. 对已驯服、属于你或满足该生物适配条件的生物使用名纸。
3. 按住 `R` 或 `V` 打开轮盘，将生物分配到需要的槽位。
4. 按 `G` 打开管理器，整理队伍、仓库和玩家设置。
5. 制作并放置“小窝”，在小窝界面中安排居民和行为模式。

载具使用“载具绑定器”绑定，不要对展示框等非载具实体使用。绑定不会永久覆盖目标原本的右键交互。

## 玩家设置与服务器配置

玩家可以在管理器的设置页中调整：

- 召唤与切换动画、音效和生物叫声
- 轮盘样式、界面动画、不透明度、字体与字号
- 伙伴状态 HUD 与召唤描边
- 骑乘视角和第一人称坐骑隐藏
- 自动编队、自动收纳、友伤保护与伙伴方块保护
- 同时部署的伙伴数量（不超过服务器上限）

服务器可以统一配置召唤冷却、玩家部署上限、高空救援触发与等待高度、小窝默认容量和活动范围、备份、睡眠恢复、契约动画以及对话文本。

## 命令

普通玩家：

- `/findme manage`：打开管理器
- `/findme hud edit`：编辑伙伴状态 HUD 位置
- `/findme hud reset`：重置 HUD 布局

管理员与整合包作者：

- `/findme reload`：重新加载生物适配与动画预设
- `/findme editor`：打开 Find Me 生物适配编辑器
- `/findme tame [目标]`：强制设置测试目标的驯服关系，仅用于管理或适配测试

## 兼容性

Find Me 的通用逻辑适用于大量原版及模组生物，并针对不同体型、移动方式和原生 AI 尽量保留原模组行为。当前还包含 Waystones、Cobblemon 以及多种龙类生物的可选适配逻辑。

模组生物的实现差异很大。如果某种生物的模型大小、动画、飞行状态、骑乘方式或所有权判断不正确，整合包作者可以通过内置编辑器和实体预设进行单独适配。

## 安装要求

- Minecraft `1.20.1`
- Minecraft Forge `47+`
- Java `17`
- ApricityUI `1.2.0+`（客户端必需依赖）

多人游戏需要服务端和所有玩家客户端都安装 Find Me；客户端还需要安装 ApricityUI。Waystones 等兼容目标不是必需依赖。

更新版本前建议正常退出世界并保留存档备份。
