# FindMe 1.3 中文使用与配置指南

## 1. 使用前必须阅读

FindMe 1.3 是测试版本，经历过多次重构，稳定性和兼容性可能不如旧版。

1. 安装或更新前备份整个世界目录。
2. 先在复制存档中测试重要生物、载具、救援、切换和跨维度功能。
3. 更换 FindMe、AUI 或生物模组版本前，先收纳已放出的对象并创建手动备份。
4. FindMe 仍保存某种实体时，不要直接删除提供该实体的模组。
5. 自定义 AI、骑乘控制器、多部位模型和特殊 NBT 的实体不保证兼容。

## 2. 版本与安装

| 游戏版本 | 加载器 | Java | 文件 |
|---|---|---:|---|
| 1.21.1 | NeoForge 21.1.230 或更高 | 21 | `find_me-1.3.0-test.1-1.21.1-neoforge.jar` |
| 1.20.1 | Forge 47.x | 17 | `find_me-1.3.0-test.1-1.20.1-forge.jar` |

客户端必须安装匹配版本与加载器的 ApricityUI。多人游戏中，FindMe 需要安装在
服务端和参与使用的客户端。不要混用两个 FindMe JAR。

NeoForge 1.21.1 提供 Cobblemon、Sable/航空学、MachineMax 和 Waystones 的可选
联动入口。Forge 1.20.1 不包含 Cobblemon 与 Sable 专用功能。

## 3. 道具与配方

所有配方均可在普通合成栏完成。

| 道具 | 配方 | 用途 |
|---|---|---|
| 名纸 | 3 张纸，无序合成 | 对生物右键，按当前绑定条件加入 FindMe |
| 载具绑定器 | 1 个铁锭 + 1 张名纸，无序合成 | 绑定受支持的载具 |
| 小窝 | 任意木质半砖 + 1 张名纸，无序合成 | 安置已绑定伙伴 |
| 定位坐垫 | 名纸在上、木棍在下 | 仅 NeoForge，用于设置 Sable 载具座位 |

非创造模式下，成功绑定会消耗名纸。管理员的强制驯服指令只改变驯服关系，
不会自动绑定或收纳。

## 4. 默认按键与轮盘操作

所有按键都可以在 Minecraft 的“控制”页面重新绑定。

| 操作 | 默认按键 |
|---|---|
| 坐骑召唤/救援 | `R` |
| 伙伴召唤 | `V` |
| 管理界面 | `G` |
| 当前对象指令 | 默认未绑定 |

- 长按坐骑或伙伴键至少 250 毫秒：打开对应轮盘。
- 短按并松开：执行当前待选对象的召唤、切换或收纳操作。
- 按住按键并滚动鼠标：不打开轮盘，直接改变待选对象。
- 左键轮盘条目：召唤未部署对象；已召唤或切换中的对象则执行收纳/取消切换。
- 只悬停并关闭轮盘：将对象设为待选，之后可以短按召唤。
- 右键生物条目：打开该生物的指令轮盘。
- 中键生物条目：打开技能轮盘（需要已安装并提供技能的附属）。
- 点击轮盘中心或按 `Esc`：取消本次轮盘操作。
- `Tab`：在坐骑与载具轮盘之间切换。
- 滚轮：切换编队或页面；数字键 `1` 到 `9` 可选择对应槽位。

状态颜色：蓝色为已召唤，灰色为待选，黄色为切换中，红色为死亡。

## 5. 坐骑、伙伴与载具

### 绑定与分类

拿名纸对生物右键。实体必须满足实体预设中的绑定条件。绑定后，FindMe 会按设置
自动创建编队或加入默认编队，并将实体记录到仓库。

- 坐骑：用于骑乘、切换和坠落救援。
- 伙伴：可以独立部署并执行跟随、停留、守卫和战斗指令。
- 载具：使用载具绑定器绑定，在坐骑轮盘内按 `Tab` 查看。

### 伙伴指令

指令按当前状态和能力显示，包括：跟随/取消跟随、原地停留、守卫这里、保护我、
停止当前行动、移动到准星位置、攻击准星目标、飞行生物落地、回家、骑乘回家，
以及安装 Waystones 时可用的传送入口。

模组生物自己的 AI 可能覆盖 FindMe 指令。守卫与家园状态会尽量限制原生跟随，
但不能保证适用于每一个第三方实体。

### 救援与切换

玩家未骑乘且处于危险下落时，坐骑按键可触发救援。默认最小下落距离为 5 格。
飞行、陆地、海洋分类会影响出生位置、移动和接取方式。切换坐骑时，新坐骑完成
接触和骑乘后，旧坐骑才正式收纳。

## 6. 小窝、编队、仓库与备份

- 小窝只接收伙伴。居民在小窝周围巡逻，不会被强制一直坐下。
- 默认巡逻半径为 64 格，默认硬边界为 128 格。
- 区域内没有任何玩家追踪时居民会被收纳；任意玩家重新加载区域后恢复。
- 相同种类的居民仍分别保存；居民之间不会互相推动。
- 地面碰撞箱位置不足时，飞行居民可使用空中位置。
- 管理界面可创建、重命名和删除编队，移动坐骑、伙伴和载具。
- 诊断页面提供手动备份、差异查看和恢复。修改版本或配置前建议手动备份。

## 7. 游戏内设置

按 `G` 打开管理界面，再进入设置。以下偏好按玩家保存，不应直接编辑 TOML。

| 设置 | 默认值 | 范围/选项 |
|---|---|---|
| 自定义名/原名/生命值显示 | 开/关/开 | 开或关 |
| 模型自动旋转 | 关 | 开或关 |
| 减少背景动画 | 开 | 开或关 |
| 长按拖选时间 | 300 ms | 150-600 ms |
| 操作音效/控制提示 | 开/开 | 开或关 |
| 自动加入/创建编队 | 开/开 | 开或关 |
| 默认编队 | 第 1 个 | 非负编队索引 |
| 名称颜色 | 关 | 开或关 |
| 名称最大长度 | 32 | 8-64 |
| 轮盘样式 | 经典圆形 | 六翼、横向战术、折叠碎片、经典圆形 |
| 文本模式 | 实用 | 关闭、实用、沉浸 |
| UI 动画 | 开 | 开或关 |
| 字体 | 默认 | 默认、无衬线、UI、人文、衬线、仿宋、楷体、等宽 |
| 字号 | 中 | 特小、小、中、大、特大 |
| 骑行自动视角 | 无 | 无、第一人称、第三人称后方、第三人称前方 |
| 默认绑定动画规则 | 同类首次 | 总是、同类首次、从不 |

切换骑行视角时，下车后会恢复原视角。临时电影流程拥有更高的短期相机控制权。

## 8. TOML 配置

首次运行后自动生成配置。通用配置通常位于 `config/find_me-common.toml`；服务器
配置通常位于世界的 `serverconfig/find_me-server.toml`。专用服务器应在停服时修改。
也可以在管理界面修改支持的项目。执行 `/findme reload` 主要重载实体预设，不等同
于安全重载所有 TOML。

### 服务器与世界规则

| 参数 | 默认 | 有效范围 | 说明 |
|---|---:|---:|---|
| `enableAutoBackups` | `true` | 布尔 | 定期备份玩家 FindMe 列表 |
| `backupIntervalMinutes` | `30` | 1-1440 | 自动备份间隔（分钟） |
| `preventBoundCreatureDeathDrops` | `true` | 布尔 | 防止绑定实体死亡物品与死亡快照重复复制 |
| `enableContractAnimation` | `true` | 布尔 | 手动绑定时播放契约流程 |
| `enableContractCinematicCamera` | `true` | 布尔 | 契约流程使用临时侧面电影镜头 |
| `enableDiagnosticLogging` | `false` | 布尔 | 输出诊断、性能、召唤、预览与兼容日志；排错时才开启 |
| `sleepReviveCooldownMinutes` | `10` | 0-10080 | 每位玩家睡眠复活尝试的冷却 |
| `sleepReviveChance` | `0.7` | 0.0-1.0 | 睡眠复活一名死亡伙伴的概率 |
| `sleepReviveSpawnEntity` | `true` | 布尔 | 复活后尝试在附近放出；关闭则保留在收纳状态 |
| `summonCooldownTicks` | `60` | 0-1200 | 召唤、战斗召唤、伙伴召唤和返回的共享冷却 |
| `companionDeploymentLimit` | `2` | 1-32 | 同时部署的伙伴上限，包含护送槽位 |
| `rescueMinFallDistance` | `5` | 0-128 | 允许救援召唤的最小下落距离 |
| `rescueHoverBaseHeight` | `12.0` | 2.0-64.0 | 飞行坐骑相对预测落点的基础等待高度 |
| `rescueHoverHeightRatio` | `0.25` | 0.0-1.0 | 超过低空窗口后，每格下落距离增加的等待高度比例 |
| `rescueHoverMaxHeight` | `48.0` | 4.0-256.0 | 飞行救援等待高度上限 |
| `enableCreatureArrivalVoice` | `true` | 布尔 | 接受召唤或救援时播放实体自己的叫声 |
| `creatureArrivalVoiceVolume` | `0.4` | 0.0-2.0 | 叫声音量 |
| `housePatrolRadius` | `64` | 64-4096 | 小窝居民巡逻半径 |
| `houseHardRadius` | `128` | 128-8192 | 小窝硬边界；运行时不会低于巡逻半径 |

### 功能模块

`modules` 下的开关默认全部开启。关闭模块不会删除已有记录。

| 参数 | 说明 |
|---|---|
| `riding` | 坐骑、载具、召唤、救援和切换 |
| `companions` | 非骑乘伙伴、部署、护送和战斗支援 |
| `management` | 管理、仓库、编队、详情和编辑器操作 |
| `houses` | 小窝分配与居民恢复；依赖伙伴模块 |
| `sleepRevival` | 睡眠复活；依赖伙伴模块与复活设置 |
| `cobblemonIntegration` | 仅 NeoForge；Cobblemon 队伍骑乘联动 |
| `sableIntegration` | 仅 NeoForge；Sable/航空学载具联动 |

### 通用视觉与对话

| 参数 | 默认 | 说明 |
|---|---:|---|
| `guiOpacity` | `1.0` | 轮盘二维元素透明度，范围 0.05-1.0，不影响 3D 模型 |
| `previewScaleOverrides` | 空 | 预览缩放覆盖，格式 `实体ID=倍率` |
| `enableDialogue` | `false` | 是否显示风格化标题/副标题对话 |
| `dialogueOverrides` | 空 | 集中覆盖对话内容 |

预览缩放示例：`dragonmounts:dragon=0.75`。倍率在自动适配之后应用。

对话格式为 `上下文=第一行|第二行`，可以重复同一上下文添加多组随机文本；只写
`上下文=` 可禁用该上下文。支持 `{player}`、`{name}`，冷却文本另支持 `{seconds}`。

可用上下文：`mount_summon`、`companion_summon`、`mount_rescue`、
`companion_combat_rescue`、`storage`、`home_summon`、`home_storage`、`home_set`、
`home_clear`、`registered`、`sleep_revive`、`sleep_revive_stored`、`blocked`、`busy`、
`cooldown`、`no_registered`、`unavailable`、`already_riding`、`occupied`、`too_high`、
`void_mount_unsafe`、`void_companion_unsafe`、`void_flying_mount`。

## 9. 实体编辑器（整合包作者）

管理员使用 `/findme editor` 打开。配置保存为实体预设，适合让原版或第三方实体
进入 FindMe。先在复制存档中验证，再用于正式整合包。

| 字段 | 可选值/格式 | 作用 |
|---|---|---|
| 分类 | 自动、坐骑、伙伴、载具、禁用 | 决定实体进入哪个系统 |
| 移动方式 | 自动、陆地、飞行、游泳 | 统一影响召唤、救援、切换和放置 |
| 绑定条件 | 自动、已驯服、主人、无视 | 决定名纸是否允许绑定 |
| 绑定动画 | 继承、总是、同类首次、从不 | 单实体类型覆盖默认契约动画规则 |
| 救援运动 | 标准 | 当前救援运动配置 |
| 碰撞/识别缩放 | 数值 | 调整 FindMe 识别与预览边界 |
| 特效大小 | 数值 | 调整魔法阵等效果的实体尺寸倍率 |
| 到达音效 | 音效 ID | 召唤出现时播放的声音 |
| 音量/音调 | 数值 | 到达音效参数 |
| 预览 NBT | SNBT/NBT 配置 | 选择特定变种用于编辑器预览 |

动画样式包括无、标准、地下出现和地下收纳。特效包括无、末影、魔法阵、高速冲击
和材质魔法阵。不要仅为了改变飞行救援而单独修改动画；移动分类才是行为来源。

绑定条件说明：

- `AUTO`：使用 FindMe 当前所有权判断。
- `TAMED`：只要实体已驯服即可绑定。
- `OWNER`：玩家必须是实体记录的主人。
- `IGNORE`：忽略驯服与主人条件，直接允许绑定。

## 10. 管理员指令

| 指令 | 权限 | 作用 |
|---|---:|---|
| `/findme manage` | 玩家 | 打开管理界面 |
| `/findme editor` | 2 | 打开实体编辑器 |
| `/findme reload` | 2 | 重载实体预设 |
| `/findme tame` | 2 | 强制驯服准星指向的实体，最大检测距离 24 格 |
| `/findme tame <target>` | 2 | 强制驯服指定实体 |

`tame` 不会绑定、收纳或自动加入编队，仅用于测试驯服与骑乘兼容。

## 11. 排错顺序

1. 确认 FindMe、加载器、游戏和 ApricityUI 版本完全匹配。
2. 在复制存档中只保留 FindMe、AUI 和目标实体模组复现。
3. 在管理界面创建手动备份。
4. 临时开启 `enableDiagnosticLogging`，只复现一次问题后关闭，避免大量日志影响性能。
5. 保留 `logs/latest.log`、崩溃报告、实体注册 ID、操作步骤和使用的 JAR 版本。
6. 若实体无法恢复，不要反复召唤或删除模组，先保留存档副本等待修复。
