# Find Me (NeoForge)

Find Me is a Minecraft NeoForge mod for 1.21.1 that keeps player-bound mounts,
companions, and vehicles manageable: bind them, summon or store them, bring
them home, and recover them more safely after difficult gameplay situations.

## Features

- Mount, companion, and vehicle binding with separate management views.
- Radial summon wheels, storage, home markers, rescue flows, and backup tools.
- Optional ceremony, magic-circle, storage, and arrival effects.
- Defensive support for vanilla and selected modded rideables without a hard
  dependency on those mods.

## Development

Requires Java 21 and NeoForge for Minecraft 1.21.1.

```powershell
.\gradlew.bat build
```

The built mod jar is written to `build/libs/`.
